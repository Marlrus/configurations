# Making VST plugins work in Reaper

## Installing Yabridge

- Search in google and go to the Github Repository for yabridge.
- Go to releases and find the last one
- Download the tr.gz file
- `cd` to your Downloads directory
- Extract the file to `~/.local/share`

```bash
tar -C ~/.local/share -xavf yabridge-5.1.1.tar.gz
```

- Verify the unpack with: `ls ~/.local/share/yabridge/yabridgectl`
- Add the yabrdige path to your `.bashrc` file: `export PATH="$PATH:$HOME/.local/share/yabridge"`
- Verify the path with `which yabridgectl`
- Tell yabridge where your windows VST plugins are:

```bash
# Example only, your location might be different
yabridgectl add "$HOME/.wine/drive_c/Program Files/Common Files/VST3"
```

- Verify the path was registered: `yabridgectl status`. You should see your VST plugins. They might say "not yet synchronized"
- Sync the loaded plugin with `yabridgectl sync`. This builds the bridge, taking the windows plugin registered with the `yabridgectl add` command, and creates the native Linux files. This should create a `~/.vst3/yabridge` directory. If you `cd` to it, you should see your `.vst3` file names as directories.
  - Those `.vst3` directories are not the actual vsts, you can verify by checking the size with the file explorer. The created directory should be around 100kB.

### Yabridge Context

The `.vst3` directories created in `~/.vst3/yabridge` are generated by yabridge. They contain a `<PLUGIN>.so` file, which is the yabridge chainloader library and a symlink to the `wine` location of the `.vst3` plugin.

The `.so` file is equivalent to a windows `.dll` file: A file that is not standalone, but code that is used by another program. One file can be used by N programs at once and a single copy in memory is used.

On Linux, a native VST is an `.so` file. Reaper loads the `.so` files which hands off to yabridge's chainloader.

1. Reaper loads the `.so` file.
2. The `.so` calls yabridge and opens the chainloader library.
3. yabridge starts a Wine process launching `yabridge-host` under Wine. The plugin runs in Wine in the BG.
4. Yabridge sits in the middle and relays between Reaper and the Wine env running the plugin.

The `.so` is the doorway, yabridge is the translator, and the real plugin runs in Wine as it needs to run in windows.
